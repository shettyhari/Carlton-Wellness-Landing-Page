# Carlton Wellness – Franchise Landing Page

Landing page for the Carlton Wellness franchise opportunity (EBG Group), with a lead-capture API and database.

## Project structure

```
api/            Vercel serverless function for the lead form (api/leads.js)
backend/        Express server: serves the page and the lead API (/api/leads)
database/       SQLite schema and init script (local data goes in database/data/, git-ignored)
deploy/         Release build script, PM2 config, nginx example and deploy guide
frontend/       The landing page: index.html, thank-you.html, favicon and images
release/        Build output: release/backend and release/frontend (generated by npm run build)
```

## Run locally

Requires Node.js 22.13 or newer (uses the built-in `node:sqlite`).

```bash
npm run install:all   # install backend dependencies
npm run db:init       # create database/data/leads.db
npm run dev           # http://localhost:3000
```

Submitting the form saves the lead to the database and sends the visitor to `thank-you.html`.

## API

| Method | Path          | Description                                                            |
|--------|---------------|------------------------------------------------------------------------|
| GET    | `/api/health` | Health check                                                           |
| POST   | `/api/leads`  | Save a lead. Required: `name`, `phone`, `email`                        |
| GET    | `/api/leads`  | List leads (`?limit`, `?offset`, `?format=csv`). Needs `ADMIN_TOKEN`   |

Configuration lives in `backend/.env` (see `backend/.env.example`).

## Content rules

- Do not use the word "spa" anywhere on the page.
- Follow EBG Group's legal terminology: "Monthly Minimum Payout Protection" (never returns or guarantees),
  "Capital Contribution" (never investment), "Business Partner" (never investor).
- Show projected payouts in rupees.

## Deploy

### Vercel

Import this repository into Vercel. No build settings are needed: `vercel.json` serves `frontend/` as a static site,
and `api/leads.js` handles form submissions as a serverless function.

Lead storage is not connected yet: each lead is validated and written to the Vercel function logs
(Project → Logs, search `NEW_LEAD`). Add storage in `api/leads.js` when ready.
